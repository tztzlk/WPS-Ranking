# WPS Ranking frontend

React + TypeScript + Vite + Tailwind SPA, deployed on Vercel (Root Directory `frontend`).

```bash
npm ci
npm run dev    # http://localhost:3000, proxies /api to the backend on :5000
npm run build
```

`VITE_API_BASE_URL` sets the API base for builds (default `/api`). See the [root README](../README.md).
